# Archives Azure YaZoo

Azure Student a servi d'environnement reel de deploiement et d'exploitation de YaZoo. Les ressources ont ensuite ete decommissionnees apres la fin de cet environnement.

Les fichiers de ce dossier sont conserves comme historique d'architecture, de CI/CD, de securite operationnelle et de retour d'experience DevOps. Ils ne decrivent plus l'environnement de demonstration actif et ne doivent pas etre utilises comme procedure de deploiement principale.

La cible showcase actuelle est provider-neutral et documentee dans [`../../DEMO_DEPLOYMENT_FREE.md`](../../DEMO_DEPLOYMENT_FREE.md).
