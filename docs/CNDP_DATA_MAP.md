# CNDP data map — YaZoo

Revue code du 8 octobre 2026. Cette cartographie décrit les traitements possibles dans le code, pas un récépissé CNDP ni une configuration d'hébergement production vérifiée. Les durées, bases juridiques, contrats et pays définitifs sont **TO VALIDATE** par le responsable et son conseil. `DATA_RETENTION_DAYS` et les délais opérationnels sont configurables ; leur valeur technique ne constitue pas une durée approuvée juridiquement.

L'export authentifié exclut mots de passe, tokens, MFA/recovery secrets, messages rédigés par autrui et secrets de paiement. La suppression ne peut pas révoquer une copie faite par un tiers ni supprimer automatiquement des backups immuables : appliquer la politique retenue aux sous-traitants et sauvegardes. Les flags CMI/realtime/scanning/SMTP/SMS doivent correspondre aux services réellement souscrits.

Avant public : compléter [les actions propriétaire](CNDP_OWNER_ACTIONS.md), faire valider les textes privacy/CGU/mentions/cookies et tester la rétention configurée. Formalités à déterminer à partir des [informations CNDP officielles](https://www.cndp.ma/notifier-un-traitement/), sans présumer de la procédure applicable.
